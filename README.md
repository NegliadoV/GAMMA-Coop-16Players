## 📥 Установка и обновление клиента (в 1 клик)

Весь дистрибутив сборки (**38.5 ГБ**, разбитый на 21 многотомный архив `gamma_coop_base.7z.001` .. `.021`, а также актуальный дельта-патч `gamma_coop_patch.7z`) размещён в разделе **[Releases v1.0.0](https://github.com/NegliadoV/GAMMA-Coop-16Players/releases/tag/v1.0.0)**.

Скачивать 21 том вручную через браузер **не требуется** — лаунчер автоматически загружает все тома в 4 параллельных потока с поддержкой докачки, проверяет контрольные суммы SHA-256 и распаковывает клиент в выбранную директорию.

### Пошаговая инструкция по установке
1. Перейдите в раздел **[Releases v1.0.0](https://github.com/NegliadoV/GAMMA-Coop-16Players/releases/tag/v1.0.0)** и скачайте архив лаунчера:
   - **`GAMMA-Coop-Launcher.zip`** (~45 МБ)
2. Распакуйте архив в любую удобную папку и запустите **`GammaZoneLauncher.exe`**.
3. Перейдите на вкладку **«⚙ УСТАНОВКА И ОБНОВЛЕНИЕ КЛИЕНТА»**.
4. В верхнем поле **«Целевая директория установки клиента (S.T.A.L.K.E.R. Anomaly + G.A.M.M.A. Co-op)»** укажите путь для установки игры (по умолчанию `C:\Anomaly`, можно выбрать любой диск, где доступно не менее **45 ГБ** свободного места).
5. Нажмите зелёную кнопку **«⬇ СКАЧАТЬ И УСТАНОВИТЬ / ОБНОВИТЬ СБОРКУ В 1 КЛИК»**.
   - **При чистой установке:** лаунчер автоматически скачает 21 том базового дистрибутива (`38.5 ГБ`), распакует их в выбранную директорию и установит актуальный патч синхронизации (`92 МБ`).
   - **При последующих обновлениях:** лаунчер пропустит базовые тома и за несколько секунд скачает только дельта-патч (`gamma_coop_patch.7z`).

## 🌐 Подключение к серверу и сетевые режимы

### Вариант 1: Через сеть Steam SDR (Рекомендуется при большом расстоянии между участниками)
Маршрутизация через магистральные ретрансляторы **Valve Steam Datagram Relay (SDR)** снижает задержку и исключает потери пакетов между регионами без использования сторонних VPN-сервисов.
1. Убедитесь, что клиент **Steam** запущен у всех участников сессии.
2. **Хост (Сервер):**
   - На вкладке **«🖥 СОЗДАНИЕ СЕРВЕРА (ДО 17 ИГРОКОВ)»** включите опцию **«🌐 Хост через сеть Steam (Valve SDR — минимальный пинг по всему миру)»**.
   - Нажмите **«⚡ БЫСТРЫЙ СТАРТ (В ЗОНУ)»**.
3. **Подключающиеся игроки (Клиенты):**
   - Запустите игру через лаунчер, откройте раздел **Co-op** в главном меню или пригласите участников через оверлей **Steam (`Shift + Tab` -> Пригласить в игру)**.

### Вариант 2: Прямое подключение по IP / Radmin VPN / ZeroTier
1. Укажите свой игровой никнейм в поле **«Позывной сталкера»** на нижней панели лаунчера.
2. Введите IP-адрес и порт хоста (например, `26.x.x.x:28666`) в поле **«Адрес сервера (IP:Порт)»**.
3. Нажмите **«ПОДКЛЮЧИТЬСЯ К СЕРВЕРУ»** — игра запустится и автоматически выполнит вход на сервер.

## ⚙️ Ключевые технические особенности

| Компонент | Описание |
| :--- | :--- |
| **Расширенный лимит игроков (`17 слотов`)** | Снято базовое ограничение движка (4 игрока). Пропатчены `AnomalyDX11AVX.exe`, `AnomalyDX11.exe`, `AnomalyDX10AVX.exe`, `AnomalyDX9AVX.exe`, `AnomalyDX8AVX.exe` (`xrr_max_players` до `16` подключаемых клиентов + `1` хост). |
| **Прямой запуск (`NVMe HardLink`)** | Все 594 активных модификации G.A.M.M.A. и патчи совместимости интегрированы в файловую структуру клиента. Запуск занимает ~3 секунды напрямую без промежуточной виртуализации `usvfs` (Mod Organizer 2). |
| **Сетевая маршрутизация Steam SDR** | Поддержка протокола Valve GameNetworkingSockets (`steam_appid.txt = 480`) для туннелирования UDP-трафика через дата-центры Valve. |
| **Автоматический спавн на Кордоне** | Новые игроки при входе на сервер автоматически инициализируются в Деревне Новичков (`l01_escape`) без рассинхронизации стартовых координат. |
| **Расширенный интерфейс отряда (`16-Slot HUD`)** | Адаптивная сетка интерфейса группы (`2x8`), поддерживающая отображение здоровья и статуса до 17 участников отряда. |
| **Мульти-инстанс на 1 ПК** | Поддержка одновременного запуска нескольких изолированных окон игры на одном компьютере (`fsgame_gamma_client2.ltx` / `appdata_client2`) для локального тестирования. |

## 📂 Структура репозитория

* `App/` — Скомпилированный автономный лаунчер `GammaZoneLauncher.exe` (не требует установки .NET Runtime) и утилиты архивации (`7z.exe`, `7z.dll`).
* `Launcher/` — Исходный код лаунчера, многопоточного загрузчика и системы дельта-обновлений (`C# / .NET 8 WinForms`).
* `xrRazom-1.4/` — Модифицированные 64-битные бинарные модули движка Anomaly 1.5.3 (`bin/`) и базовые сетевые скрипты `xrRazom`.
* `xrRazom-GAMMA-fixes/` — Модули совместимости 594 модификаций S.T.A.L.K.E.R. G.A.M.M.A. с сетевой синхронизацией.
* `patch_16_players.py` — Скрипт бинарного патчинга исполняемых файлов `AnomalyDX*.exe` для снятия лимита игроков.
